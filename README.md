# 雾光 · 音乐桌面

**让正在听的歌，成为桌面的一部分。**

雾光是一款运行在 Wallpaper Engine 中的动态音乐壁纸。轻盈的半透明播放器、实时歌词、时间日期与流动背景，让桌面在工作、学习和听歌时保持自己的节奏。

你仍然在网易云音乐或 QQ 音乐里听歌。安装雾光音乐助手后，桌面会自动识别支持的音乐客户端，显示歌曲、专辑封面和播放状态，无需手动把歌曲导入壁纸。

**首次使用只需三步：**

1. 在创意工坊订阅壁纸，等待下载完成，在 Wallpaper Engine 中应用。
2. 在本仓库 Releases 下载并安装音乐助手，安装完成后启动。
3. 打开网易云音乐或 QQ 音乐，开始播放歌曲。

壁纸和助手是两部分：**订阅壁纸不会自动安装助手。** 不安装助手也可以使用时钟和内置背景；音乐信息、歌词、系统音量控制和自定义壁纸库需要助手运行。

## 它能帮你解决什么

- **桌面不知道你正在听什么？** 自动同步当前歌曲、歌手与封面，切歌后随客户端更新。
- **每次都要手动维护壁纸歌单？** 网易云模式直接读取本机当前播放队列，无需逐首添加。这里的“歌单同步”指当前播放队列，不是同步账号收藏的全部歌单。
- **想看歌词又不想一直打开音乐窗口？** 将可获取的歌词同步到桌面，随播放进度显示。
- **壁纸音量与系统音量各调各的？** 播放器音量控制跟随 Windows 系统主音量，调节会影响系统整体输出。
- **喜欢自己的背景？** 内置背景可直接切换，也可把图片和视频放入自定义文件夹，让壁纸库自动刷新。

## 音乐客户端支持范围

| 功能 | 网易云音乐 | QQ 音乐 |
| --- | --- | --- |
| 自动识别客户端 | 支持 | 支持 |
| 当前歌曲、歌手与封面 | 支持 | 支持 |
| 当前播放队列 | 支持读取本机队列 | 暂不支持完整队列 |
| 歌词 | 可获取匹配歌词时显示 | 可获取匹配歌词时显示 |
| 播放状态与进度 | 取决于客户端提供的数据 | 取决于客户端提供的数据 |
| 播放 / 暂停、上一首 / 下一首 | 取决于客户端的系统媒体控制支持 | 取决于客户端的系统媒体控制支持 |
| 点击进度条跳转 | 取决于客户端是否允许跳转 | 取决于客户端是否允许跳转 |

当前支持 Windows 桌面客户端。不同版本、歌曲类型和媒体状态可能影响识别、歌词及控制能力；暂不承诺所有版本都能完整联动。两个客户端同时运行时，建议只让一个处于播放状态。

## 为长期驻留桌面而设计

曲面玻璃感播放器与柔和背景保持统一。歌词下方的轻盈曲线可响应 Wallpaper Engine 音频数据，时间日期保持清晰，界面位置和透明度可以按自己的桌面调整。

![桌面设置与背景选择](settings.jpg)

- 播放器可收起，歌词可显示或隐藏。
- 背景选择支持上下翻页；图片和视频都可以作为背景。
- 设置支持背景缩放与位置、鼠标轻移、布局、时间日期、歌词位置与动效。
- 可调整播放器、播放列表与设置面板透明度，选择设置文字颜色。
- 设置会自动记住，适合搭配浅色或深色壁纸长期使用。

## 运行要求

- Windows 10 1809 或更新版本的 64 位 Windows。
- 已安装 Wallpaper Engine；壁纸需要通过该软件运行。
- 音乐联动需要雾光音乐助手和支持的网易云 / QQ 音乐桌面客户端。
- 无需另外安装 Python。查询歌曲信息、封面和歌词时需要网络。

内置动态背景可直接使用。添加自己的 MP4 前，请在助手托盘菜单选择 **启用 MP4 视频支持（首次下载）**，按提示下载约 30 MB 的视频工具。首次处理新视频会生成兼容缓存，可能短时占用 CPU，不会修改原文件。

## 数据与更新

助手通过本机连接与壁纸通信，读取系统媒体状态、网易云本地播放队列和系统主音量；会向音乐平台公共接口请求歌曲信息及歌词，不要求输入音乐账号密码，也不上传播放记录。

自定义背景、歌词缓存和日志保存在本机用户目录。壁纸通过创意工坊更新，助手通过 Releases 单独更新。安装包当前未做代码签名，可用发布附件中的 `SHA256SUMS.txt` 核对下载文件。
